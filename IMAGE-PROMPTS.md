## How to use

1. **Always attach one of your uniform sample images** to each generation and add:
   *"Match the uniform exactly to the attached reference image."*
   This is the only reliable way to keep the uniform consistent across images.
2. Start every prompt with the **STYLE block**, then the right **UNIFORM block**,
   then the scene text from the list below.
3. Size guide in ChatGPT: **Portrait = 1024×1536**, **Landscape = 1536×1024**,
   Square = 1024×1024. Each prompt states which one.
4. For cutout images (marked **WHITE BG**) the figure must be fully inside the
   frame — nothing cropped at the edges — or I can't cut it out cleanly.
